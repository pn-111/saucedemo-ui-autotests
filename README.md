# Автотесты для UI SauceDemo

Данный репозиторий содержит автоматизированные UI-тесты для веб-приложения [SauceDemo](https://www.saucedemo.com/). 

## Стек технологий
* **Язык программирования:** Python 3.x
* **Инструмент автоматизации:** Playwright
* **Фреймворк для тестирования:** Pytest
* **Паттерн проектирования:** Page Object Model (POM)

## Структура проекта
* `pages/` — классы Page Object (локаторы и методы для взаимодействия со страницами)
* `tests/` — файлы с тестами, разделенные по функциональности (авторизация, корзина, оформление заказа и т.д.)
* `conftest.py` — фикстуры Pytest (настройка и закрытие браузера)
* `requirements.txt` — зависимости проекта

## Запуск тестов
Для запуска тестов необходимо установить зависимости и браузеры Playwright:

```bash
# Установка зависимостей
pip install -r requirements.txt

# Установка браузеров для Playwright
playwright install

# Запуск всех тестов
pytest
